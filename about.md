The creation of Data For Climate Action Edinburgh was inspired by the setting up of the Our Future Edinburgh initiative in 2022. The code the group shares, and the associated data, are available on the D4CAE GitHub repository (ie a version control system):

[GitHub](https://github.com/Data-4-Climate-Action-Edinburgh/Data4ClimateActionEdinburgh_Code_etc)
