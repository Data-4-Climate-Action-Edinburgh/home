# What is D4CAE?

[Data For Climate Action Edinburgh (D4CAE) is a group of volunteers](https://data-4-climate-action-edinburgh.github.io/home/2023-08-06-A-group-of-volunteers/) , using data skills to support other voluntary groups involved in climate action in and around Edinburgh. The creation of D4CAE was inspired by the setting up of the 'Our Future Edinburgh' initiative in 2022.

We share the code we write, and the associated data, on the D4CAE GitHub repository (a version control system) where they are available under an open-source licence:

[Data4ClimateActionEdinburgh_Code_etc repo on GitHub](https://github.com/Data-4-Climate-Action-Edinburgh/Data4ClimateActionEdinburgh_Code_etc)

# Get in touch

If you could use some help with your climate or biodiversity data, or if you'd like to join our mailing list to hear about volunteering opportunities, please email us - [data4climateactionedinburgh\@gmail.com](mailto:data4climateactionedinburgh@gmail.com) !
