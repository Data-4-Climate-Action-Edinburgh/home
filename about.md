# What is D4CAE?

[Data For Climate Action Edinburgh (D4CAE) was a group of volunteers](https://data-4-climate-action-edinburgh.github.io/home/2023-08-06-A-group-of-volunteers/) , using data skills to support other voluntary groups involved in climate action in and around Edinburgh from 2022 to 2026. The creation of D4CAE was inspired by the setting up of the 'Our Future Edinburgh' initiative in 2022.

We shared the code we wrote, and the associated data, on the D4CAE GitHub repository (a version control system) where they remain available under an open-source licence:

[Data4ClimateActionEdinburgh_Code_etc repo on GitHub](https://github.com/Data-4-Climate-Action-Edinburgh/Data4ClimateActionEdinburgh_Code_etc)

The email address will no longer be monitored, as of 3 October 2026.
